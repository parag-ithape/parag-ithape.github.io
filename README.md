## Run locally

This is a static site. Clone the repository and open `index.html` in a browser, or run a local static server:

```bash
python -m http.server 8000
```

Then open http://localhost:8000.

## Deployment

GitHub Pages serves the production site from the configured publishing source. The `portfolio-v2-preview` branch is a review copy; it does not change the production site until its changes are merged and deployed.
